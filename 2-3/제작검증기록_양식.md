# 제작·검증 기록: 2-3

## 수정 기록

### 수정 기록 1
- 발견한 문제: 펫의 성장이 너무 빠르게 진행되고 펫의 레벨 한계가 정해지지 않음.

- AI에게 전달한 요청: 일정 1개 당 1레벨이 오르지 않고 전체 스케쥴의 갯수를 반영해서 경험치가 보이고 그에 따라 펫의 이미지 바뀔 수 있게 바꿔줘. 최대 레벨은 6레벨로 제한 할게.

- 수정 후 테스트 결과: 전체 스케줄의 7분의 1로 경험치를 세분화 해서 경험치가 가시적으로 보이게 수정됨.

- 수정 이유: 사용자가 서비스를 사용할 때 동기부여가 더 될 것이고 게임처럼 경험치가 한눈에 보이는 것이 펫 기능의 유무가 더 뚜렷하게 보임.


## 사용자 테스트
- 테스트 참여자와 요청한 작업 : 코디세이 평가 진행 인원, 사이드 바를 통해서 스케줄 추가.
- 사용자의 행동과 질문 : 스케줄을 정렬하는 기능은 없는지? , 모바일 버전에서 UI가 불편함, 자신의 이름과 펫 이름 설정이 있으면 좋겠음.
- 받은 피드백 : 왼쪽 사이드 바에 카테고리를 추가할 수 있어야 더 유연한 사용 경험이 가능. 일정들 간의 정렬을 기준을 추가 혹은 사용자 맞춤으로 정렬. 
- 반영 내용과 결과 : 플래너 반영_플래너.html로 저장
