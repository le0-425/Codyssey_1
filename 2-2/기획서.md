# 하루 시간 및 스케줄 관리 투두리스트 기획서

---

## 1. 기획 배경

- 미팅, 회의, 수업, 학원, 출장처럼 **성격이 다른 일정**이 하루에 섞이면 메모장이나 일반 캘린더로는 하루의 흐름이 한눈에 들어오지 않는다.
- 캘린더 앱은 기능이 많은 대신 일정 하나를 넣는 과정이 길고, "오늘 시간을 어디에 얼마나 쓰는지"를 직관적으로 보여 주지 않는다.
- 이 서비스는 **"하루 하나, 한 페이지"** 에 집중한다.
  - 입력: 카드를 끌어다 놓는 동작만으로 끝낸다.
  - 결과: **표(무엇을)** 와 **시계(언제, 얼마나)** 두 가지로 동시에 보여 준다.
  - 동기: 완료 체크에 따라 **펫이 자라서**, 계획을 끝까지 해내는 재미를 준다.

---

## 2. 대상 사용자

### 2-1. 주요 대상

- 하루 스케줄 관리가 필요한 모든 사람
- 미팅, 회의, 출장이 잦은 **직장인**
- 전공 수업, 교양 수업, 학원이 섞여 있는 **학생 및 취업 준비생**
- 이동 중에도 **휴대폰으로** 오늘 일정을 확인하고 바로 고치고 싶은 사람

### 2-2. 사용자 페르소나

| 구분 | 페르소나 A (샘플 인물) | 페르소나 B | 페르소나 C |
|---|---|---|---|
| 이름 | 김민수 (가상) | 이서연 (가상) | 박준호 (가상) |
| 직업 | IT 프론트엔드 개발자 | 대학교 3학년 | 해외영업팀 과장 |
| 하루 특징 | 데일리 스크럼, UI 리뷰, 고객사 방문, 퇴근 뒤 영어 학원과 온라인 강의 | 전공·교양 수업과 저녁 학원 | 국내·해외 출장과 시차 있는 회의 |
| 고민 | 회의와 외근 사이에 남는 시간이 얼마인지 모르겠다 | 전공 공부와 취미 학습의 균형 | 출장과 회의를 한 화면에서 보고 싶다 |
| 주로 쓰는 기능 | 시계의 "하루 중 계획 %"와 카테고리별 합계 | 본업/취미 태그가 붙은 수업·학원 카테고리 | 국내/해외 출장 카테고리, 휴대폰 탭 입력 |

### 2-3. 사용 상황

| 시점 | 기기 | 하는 일 |
|---|---|---|
| 출근 전 | PC | 시간 카드를 만들고 카테고리와 함께 표에 끌어다 놓아 하루 구성 |
| 이동 중 | 휴대폰 | 카테고리·시간 카드를 탭해 고른 뒤 표를 탭해 일정 추가·수정, 표와 시계 확인 |
| 하루 중간 | PC·휴대폰 | 끝난 일정 완료 체크, 펫 레벨 확인 |
| 하루 마무리 | PC | 시계와 카테고리별 합계로 오늘 시간 사용 돌아보기 |

## 3. 화면 구성

### 3-1. 전체 레이아웃 (PC, 화면 폭 900px 초과)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [김]  김민수 plan                              일정 0개 · 완료 0개 · 계획 0분 │
│       IT 프론트엔드 개발자 · 2026년 11월 13일 (금)                         │
├────────────────┬──────────────────────────────────┬──────────────────┤
│ 프로필          │ 오늘의 스케줄 표                   │ 시간 입력          │
│  이름           │ [샘플 일정 채우기] [모두 비우기]      │  시작 / 종료       │
│  직업 · 직책    │ ┌──────────────────────────────┐ │  일정 내용         │
│                │ │완료│카테고리│일정 내용│시간│관리 │ │  [시간 카드 만들기] │
│ 스케줄 카테고리  │ │                              │ │                  │
│  🤝 미팅        │ │   (비어 있으면 안내 문구)       │ │ 만든 시간 카드      │
│  🗂️ 회의        │ └──────────────────────────────┘ │  🕒 09:30–09:50    │
│  📘 전공 수업   │                                  │  🕒 15:00–16:00    │
│  ...           │ 나의 펫 모찌                       │  🕒 19:30–21:00    │
│                │  🥚  Lv.1 알 · 완료한 일정 0개      ├──────────────────┤
│                │  ▓░░░░░░░░                        │ 24시간 시계         │
│                │                                  │  (도넛 시계 + %)    │
│                │                                  │  계획된 / 남은 시간  │
│                │                                  │  카테고리별 합계     │
├────────────────┴──────────────────────────────────┴──────────────────┤
│ ※ 가상 예시 안내 · 저장되지 않음 안내                                     │
└──────────────────────────────────────────────────────────────────────┘
```

- 세 영역의 너비: 왼쪽 **260px** / 가운데 **나머지 전부** / 오른쪽 **310px**
- 화면 폭 1100px 이하에서는 왼쪽 230px, 오른쪽 280px로 줄어든다.
- 전체 최대 너비는 1440px이며 가운데 정렬한다.

### 3-2. 헤더 (화면 상단)

| 요소 | 내용 |
|---|---|
| 아바타 | 이름의 첫 글자(예: "김")를 파랑~보라 그라데이션 사각형에 표시 |
| 타이틀 | **"김민수 plan"** — 이름은 검정, "plan"은 강조색(파랑) |
| 보조 줄 | 직업·직책 · 오늘 날짜(예: 2026년 11월 13일 (금)) |
| 요약 알약 | 일정 N개 · 완료 N개 · 계획 N시간 N분 |

- 이름과 직업은 헤더에서 직접 고치지 않고, **왼쪽 사이드 바의 프로필 카드**에서 고친다.
- 이름을 지우면 타이틀은 "나의 plan", 직업을 지우면 "직업 미입력"으로 표시된다.
- 브라우저 탭 제목도 "○○○ plan"으로 함께 바뀐다.

### 3-3. 왼쪽 사이드 바

#### (1) 프로필 카드

| 입력칸 | 기본값 | 글자 수 제한 | 반영 위치 |
|---|---|---|---|
| 이름 | 김민수 | 12자 | 헤더 타이틀, 아바타, 탭 제목 |
| 직업 · 직책 | IT 프론트엔드 개발자 | 30자 | 헤더 보조 줄 |

- 입력하는 즉시 화면에 반영된다.
- 펫 이름은 **"모찌"로 고정**이며 바꿀 수 없다.

#### (2) 스케줄 카테고리 카드

기본 카테고리 8개를 묶음별로 세로로 나열한다. 카드마다 아이콘, 이름, 구분 태그가 있고 왼쪽 테두리가 카테고리 색이다.

| 묶음 | 카테고리 | 구분 태그 | 아이콘 | 색상 |
|---|---|---|---|---|
| 업무 | 미팅 | - | 🤝 | `#3b82f6` 파랑 |
| 업무 | 회의 | - | 🗂️ | `#6366f1` 남색 |
| 수업 (본업 / 취미) | 전공 수업 | 본업·주요 | 📘 | `#0d9488` 청록 |
| 수업 (본업 / 취미) | 교양 수업 | 취미 | 📗 | `#22a35a` 초록 |
| 학원 (본업 / 취미) | 실무·자격 학원 | 본업·주요 | 🏫 | `#e08a00` 주황 |
| 학원 (본업 / 취미) | 언어·취미 학원 | 취미 | 🗣️ | `#e0468f` 분홍 |
| 출장 | 국내 출장 | 국내 | 🚄 | `#e5484d` 빨강 |
| 출장 | 해외 출장 | 해외 | ✈️ | `#0284c7` 하늘 |

- **표에 추가:** 카드를 가운데 표로 끌어다 놓으면 일정이 추가된다. (4장 참고)
- 카테고리는 **고정 8개**이며 추가·삭제·순서 변경·이름과 색 변경은 지원하지 않는다.
- 수정 중인 일정이 있으면 카드 위에 주황색 안내 문구가 나타난다. (4-4 참고)

### 3-4. 가운데 영역

#### (1) 오늘의 스케줄 표

| 열 | 내용 |
|---|---|
| 완료 | 체크박스 (카테고리 색) |
| 카테고리 | 아이콘 + 이름 배지. 없으면 "카테고리 미지정" |
| 일정 내용 | 시간 카드에 적은 내용. 없으면 "내용 없음" |
| 시간 | 시작 – 종료, 아래에 소요 시간. 없으면 "시간 미정" |
| 관리 | [수정] [삭제] |

- **처음 열면 빈 표**와 함께 🗓️ "아직 일정이 없어요" 안내가 나온다.
- 일정 줄은 **카테고리 색을 옅게 깐 배경** + 왼쪽에 진한 카테고리 색 테두리로 표시된다.
- 무언가를 넣거나 바꾸면 그 줄이 카테고리 색으로 잠깐 **반짝인다**.
- 완료한 줄은 일정 내용에 취소선이 그어지고 회색으로 바뀐다.
- 줄에 마우스를 올리면 그 줄과 **시계의 같은 일정 부채꼴이 함께 강조**된다.
- 일정은 **추가한 순서대로** 쌓이며 시간순으로 자동 정렬하지 않는다.
- 표 폭이 600px보다 좁아지면 표 안에서 가로로 스크롤된다.

#### (2) 표 위 도구

| 도구 | 동작 |
|---|---|
| 샘플 일정 채우기 | 김민수의 샘플 일정 5개로 채움. 이미 일정이 있으면 확인창을 띄움 |
| 모두 비우기 | 확인창 뒤 표의 모든 일정 삭제 |

샘플 일정 5개:

| 카테고리 | 내용 | 시간 |
|---|---|---|
| 회의 | 데일리 스크럼 | 09:30 – 09:50 |
| 미팅 | 디자이너와 결제 화면 UI 리뷰 | 11:00 – 12:00 |
| 국내 출장 | 판교 고객사 방문 · 대시보드 시연 | 14:00 – 17:00 |
| 언어·취미 학원 | 영어 회화 학원 | 19:30 – 21:00 |
| 전공 수업 | React 성능 최적화 온라인 강의 | 21:30 – 22:30 |

#### (3) 나의 펫 카드

- 원형 무대 위에 펫(이모지)이 서 있고, 옆에 이름, 레벨, 경험치 막대, 안내 메시지가 있다.
- 자세한 성장 규칙은 6장에 정리한다.

### 3-5. 오른쪽 사이드 바

#### (1) 시간 입력 카드

| 입력칸 | 설명 |
|---|---|
| 시작 / 종료 | 시각 선택칸 (나란히 배치) |
| 일정 내용 | 40자, 예: 스프린트 회고 |
| [시간 카드 만들기] | 입력한 시간으로 시간 카드를 만들어 목록 맨 위에 추가 |

- 오류 안내: 시작·종료 중 하나라도 비면 "시작과 종료 시간을 모두 입력하세요.", 둘이 같으면 "시작과 종료 시간이 같아요."
- 종료가 시작보다 이르면(예: 23:00 – 01:00) **자정을 넘기는 일정**으로 받아들이고, 표에 "· 다음 날까지"를 붙인다.
- Enter 키로도 카드를 만들 수 있다.
- 카드를 만든 뒤에는 일정 내용 칸만 비워지고, 시작·종료 시간은 그대로 남는다.

#### (2) 만든 시간 카드 목록

- 카드에는 🕒 시작 – 종료, 일정 내용과 소요 시간, × 삭제 버튼이 있다.
- 처음 열면 예시 카드 3개가 준비되어 있다: `09:30–09:50 데일리 스크럼`, `15:00–16:00 스프린트 계획 회의`, `19:30–21:00 영어 회화 학원`
- 카드는 표에 놓아도 사라지지 않아 **여러 번 재사용**할 수 있다.
- 카드가 없으면 "위에서 시간을 입력해 카드를 만들어 보세요." 안내가 나온다.

#### (3) 24시간 시계 카드

- 하루 24시간을 하나의 도넛 모양 원에 담는다. **맨 위가 0시**, 오른쪽 6시, 아래 12시, 왼쪽 18시.
- 1시간마다 눈금, 6시간마다 굵은 눈금, 3시간마다 숫자를 표시한다.
- 표에 시간이 들어간 일정은 그 시간대만큼 **카테고리 색 부채꼴**로 채워진다. 완료한 일정은 반투명하게 바뀐다. 시간이 없는 일정은 시계에 나타나지 않는다.
- 가운데에는 **현재 시각 바늘**과 **"하루 중 계획 N%"** 를 표시한다. 바늘은 30초마다 갱신된다.
- 부채꼴에 마우스를 올리면 그 부채꼴과 표의 해당 줄이 함께 강조되고, 일정 이름과 시간이 말풍선으로 나온다.
- 아래 요약:

| 항목 | 계산 |
|---|---|
| 계획된 시간 | 일정이 차지한 시간대의 합. **겹친 시간은 한 번만** 셈 |
| 남은 빈 시간 | 24시간 − 계획된 시간 |
| 카테고리별 합계 | 카테고리 색 + 이름 + 합계 시간. 시간 미정 일정은 "시간 미정 일정 N개"로 따로 표시 |

## 4. 핵심 동작

### 4-1. 일정 하나를 만드는 기본 흐름

```
① 오른쪽에서 시작·종료·내용 입력 → [시간 카드 만들기]
② 왼쪽 카테고리 카드를 가운데 표의 빈 곳에 놓기
      → 새 줄 생성, 카테고리 색으로 옅게 칠해짐 (시간은 "시간 미정")
③ 오른쪽 시간 카드를 방금 생긴 줄 위에 놓기
      → 시간과 소요 시간이 들어감, 내용이 비어 있으면 카드의 내용도 들어감
④ 24시간 시계에 그 시간대가 카테고리 색으로 채워지고, 헤더·요약 숫자가 갱신됨
```

- 순서를 바꿔 **시간 카드를 먼저** 빈 곳에 놓아도 된다. 이 경우 시간이 있는 "카테고리 미지정" 줄이 생기고, 그 위에 카테고리를 놓으면 완성된다.

### 4-2. 끌어다 놓기 규칙

| 무엇을 | 어디에 | 결과 |
|---|---|---|
| 카테고리 | 표의 빈 곳 | 그 카테고리의 새 일정 줄 추가 |
| 카테고리 | 기존 일정 줄 | 그 줄의 **카테고리가 바뀜** |
| 시간 카드 | 표의 빈 곳 | 그 시간과 내용으로 새 일정 줄 추가 (카테고리 미지정) |
| 시간 카드 | 기존 일정 줄 | 그 줄의 **시간이 카드 시간으로 바뀜**, 내용은 비어 있을 때만 채움 |
| 무엇이든 | 그 밖의 곳 | 아무 일도 없음 |

- 끌기 시작하면 카드의 반투명 복사본이 손끝을 따라오고, 원래 카드는 흐려진다.
- 끄는 동안 표 전체에 점선 테두리가 생기고, 놓을 위치(빈 곳 또는 특정 줄)는 강조색으로 표시된다.
- 6px 이상 움직여야 끌기로 인정하고, 그보다 적게 움직이면 **탭(클릭)** 으로 처리한다.
- 마우스와 터치를 같은 방식(포인터 이벤트)으로 처리해, PC와 휴대폰에서 모두 끌어다 놓을 수 있다.

### 4-3. 탭해서 고르기 → 탭해서 놓기

끌기가 어려운 상황(휴대폰, 트랙패드)을 위한 두 번째 입력 방법이다.

1. 카테고리 카드나 시간 카드를 **탭**하면 "선택됨" 상태가 된다.
2. 화면 아래에 검은 안내 막대가 떠서 "‘미팅’ 선택됨 · 표의 일정 줄이나 빈 곳을 탭하세요"라고 알려 준다.
3. 표의 **빈 곳**을 탭하면 새 일정, **일정 줄**을 탭하면 그 줄에 반영된다.
4. 같은 카드를 다시 탭하거나 [취소] 또는 Esc 키를 누르면 선택이 풀린다.

### 4-4. 수정

> **원칙: 가운데 표에서는 직접 고치지 않는다. 수정은 항상 양쪽 사이드 바에서 한다.**

1. 표의 **[수정]** 을 누르면 그 줄에 주황 테두리가 생기고 버튼이 "수정 중"으로 바뀐다.
2. **오른쪽 사이드 바**가 "✏️ 일정 수정" 모드로 바뀌고(카드에 주황 테두리), 그 일정의 시작·종료·내용이 입력칸에 채워진다. 버튼은 [수정 적용] / [취소].
3. **왼쪽 카테고리 카드** 위에 "✏️ 수정 중인 일정이 있어요. 카테고리를 탭하면 그 일정의 카테고리가 바로 바뀝니다." 안내가 뜬다.
4. 수정 중에는:
   - 카테고리를 탭 → 그 일정의 카테고리가 즉시 바뀜
   - 시간 카드를 탭 → 그 일정의 시간이 카드 시간으로 바뀌고 입력칸에도 반영됨
   - 입력칸을 고치고 [수정 적용] → 시간과 내용이 반영되고 수정 모드 종료
5. [취소], "수정 중" 버튼 다시 누르기, Esc 키로 수정 모드를 끝낸다.
6. 화면 폭 900px 이하에서는 [수정]을 누르면 시간 입력 카드가 보이도록 화면이 자동으로 스크롤된다.

### 4-5. 삭제

| 대상 | 방법 | 확인창 |
|---|---|---|
| 일정 한 개 | 표의 [삭제] | 없음 (바로 삭제, 시계에서도 함께 사라짐) |
| 일정 전체 | [모두 비우기] | 있음 |
| 시간 카드 | 카드의 × | 없음 |

- 확인창은 브라우저 기본 확인창을 사용한다.
- 수정 중인 일정을 삭제하면 수정 모드도 함께 끝난다.

### 4-6. 완료 체크

- 체크박스를 누르면 완료, 다시 누르면 취소된다.
- 완료하면 표의 취소선, 시계 부채꼴의 반투명 처리, 헤더의 완료 개수, 펫 성장이 한꺼번에 갱신된다.

### 4-7. Esc 키 동작 순서

탭 선택 풀기 → 수정 모드 끝내기 (앞의 것이 열려 있으면 그것만 처리)

## 5. 모바일 화면

### 5-1. 태블릿·휴대폰 (화면 폭 900px 이하)

- 세 영역이 **한 줄로 세로 배치**된다. 순서는 **왼쪽(프로필·카테고리) → 가운데(스케줄 표·펫) → 오른쪽(시간 입력·시계)** 이다.
- 카테고리 카드는 **2열**로 배치된다.
- 펫 카드는 세로 배치로 바뀌고 내용이 가운데 정렬된다.
- 카드를 **탭**하면 화면 아래에 탭 안내 막대가 떠서, 화면을 스크롤해 표를 탭하면 반영된다.
- 표는 폭이 좁으면 가로로 스크롤된다.
- 끌어다 놓기도 터치로 그대로 쓸 수 있다.

### 5-2. 작은 휴대폰 (화면 폭 420px 이하)

- 카테고리 카드가 **1열**로 바뀐다.
- 헤더 타이틀 글자 크기를 줄인다. (24px → 21px)

## 6. 나의 펫 성장

### 6-1. 성장 규칙

- **성장 기준 = 완료한 일정의 개수**이다.
- 완료 개수가 기준에 닿을 때마다 한 단계씩 오르고, **7개 이상이면 최고 단계 Lv.6**이 된다.

| 레벨 | 완료한 일정 | 모습 | 이름 |
|---|---|---|---|
| Lv.1 | 0개 이상 | 🥚 | 알 |
| Lv.2 | 1개 이상 | 🐣 | 부화 중 |
| Lv.3 | 2개 이상 | 🐥 | 아기 병아리 |
| Lv.4 | 3개 이상 | 🐤 | 꼬마 새 |
| Lv.5 | 5개 이상 | 🐦 | 파랑새 |
| Lv.6 | 7개 이상 | 🦚 | 공작새 |

- 예: 일정 5개 중 3개 완료 → Lv.4 꼬마 새
- 펫 크기는 완료 개수에 따라 커진다. (44px에서 시작해 완료 1개마다 5px씩, 10개까지)

### 6-2. 화면 표시

- 레벨 줄: "Lv.4 **꼬마 새** · 완료한 일정 3개"
- 경험치 막대: 파랑에서 분홍으로 이어지는 그라데이션. 현재 단계에서 다음 단계까지의 진행도를 채우고, 최고 단계에서는 가득 찬다.
- 안내 메시지:

| 상황 | 메시지 |
|---|---|
| 진행 중 | 일정을 N개 더 완료하면 ‘파랑새’(으)로 자라요. |
| 일정이 있고 전부 완료 | 오늘 일정을 전부 끝냈어요! 모찌가 신나서 뛰고 있어요 🎉 |
| 최고 단계 | 최고 단계까지 성장했어요! |

### 6-3. 효과

- **완료 개수가 늘 때:** 펫이 커졌다 작아지며 흔들리는 "통" 효과와 함께 ✨⭐💖 반짝이 8개가 사방으로 퍼진다.
- **전부 완료:** 펫 카드 배경이 노랑·분홍·파랑 그라데이션으로 바뀌고 펫이 계속 깡충깡충 뛴다.
- 완료를 취소하면 레벨도 내려간다. (내려갈 때는 효과 없음)
- 샘플 채우기나 모두 비우기를 하면 효과 기준이 처음부터 다시 시작한다.

## 7. 완료 기준

| 번호 | 기준 | 확인 방법 |
|---|---|---|
| 1 | HTML 파일을 열면 가운데에 **빈 스케줄 표**가 나오고, 왼쪽에 카테고리 8개, 오른쪽에 시간 입력칸과 시간 카드 3개가 있다 | 파일을 처음 열었을 때 화면 확인 |
| 2 | 카테고리를 끌어 표에 놓으면 그 줄이 **카테고리 색으로 옅게** 칠해진다 | 카테고리 8개를 각각 놓아 보기 |
| 3 | 시간 카드를 일정 줄에 놓으면 시간이 들어가고, **24시간 시계에 그 시간만큼 색이 늘어난다** | 줄을 하나씩 채우며 시계와 "계획된 시간" 확인 |
| 4 | 표와 시계가 연동된다 (추가·삭제·완료·수정이 즉시 반영, 마우스를 올리면 서로 강조) | 각 동작 후 시계 확인 |
| 5 | 수정은 사이드 바에서만 이루어진다 | 표의 칸을 눌러도 편집되지 않는지, [수정] 후 사이드 바에서 고쳐지는지 확인 |
| 6 | 완료 체크에 따라 펫이 Lv.1 ~ Lv.6으로 자란다 | 샘플 5개를 하나씩 체크 |
| 7 | 휴대폰에서 탭 입력으로 모든 기능을 쓸 수 있다 | 휴대폰 또는 개발자 도구 모바일 보기 |
| 8 | 다른 파일이나 로그인 없이 **HTML 파일 하나로** 열린다 | 인터넷을 끄고 파일 열기 |
| 9 | 화면 하단에 가상 예시 문구가 있다 | 푸터 확인 |

## 8. 한계 및 비목표

1. **로그인과 기록 저장은 하지 않습니다.** 새로고침하거나 창을 닫으면 시간 카드, 일정, 프로필이 모두 처음 상태로 돌아갑니다.
2. **가운데 스케줄 표에서는 직접 수정할 수 없습니다.** 시간과 내용은 오른쪽 사이드 바, 카테고리는 왼쪽 사이드 바에서 고칩니다.
3. **하루 단위만 다룹니다.** 날짜 이동, 주간·월간 보기, 반복 일정, 알림은 제공하지 않습니다.
4. **시간이 겹치는 일정에 경고를 띄우지 않습니다.** 둘 다 표에 들어가며, 시계의 "계획된 시간"은 겹친 시간을 한 번만 셉니다.
5. **일정 하나를 지울 때는 확인창이 없습니다.** 되돌리기(실행 취소) 기능도 없습니다.
6. **카테고리는 기본 8개로 고정**입니다. 추가, 삭제, 순서 변경, 이름·색 변경을 할 수 없습니다.
7. **표의 정렬 기능이 없습니다.** 일정은 추가한 순서대로 쌓이며, 시간순 정렬이나 직접 순서 바꾸기를 제공하지 않습니다.
8. **해외 출장의 시차는 계산하지 않습니다.** 모든 시간은 기기의 현지 시각 기준입니다.
9. 자정을 넘기는 일정은 하나로 입력할 수 있지만 "오늘"의 시계 위에 이어서 그려지며, 다음 날 표로 넘어가지 않습니다.
10. 펫은 그날의 화면 안에서만 성장하며 다음에 열었을 때 이어지지 않습니다. 펫 이름도 바꿀 수 없습니다.
11. 다른 캘린더(구글 캘린더 등)와 연동하거나 다른 사람과 공유하는 기능은 없습니다.

## 9. 검증 방법

### 9-1. 첫 화면

- [ ] 표가 비어 있고 "아직 일정이 없어요" 안내가 보인다.
- [ ] 헤더에 "김민수 plan", 직업, 오늘 날짜, 일정 0개·완료 0개·계획 0분이 보인다.
- [ ] 왼쪽에 기본 카테고리 8개(출장 국내/해외, 수업·학원 본업/취미 구분 포함), 오른쪽에 시간 카드 3개가 있다.
- [ ] 시계에 "0%", 계획된 시간 0분, 남은 빈 시간 24시간이 보인다.

### 9-2. 사이드 바 → 표 → 시계 연동

- [ ] 카테고리를 표의 빈 곳에 놓으면 새 줄이 생기고 카테고리 색으로 칠해진다.
- [ ] 카테고리를 기존 줄에 놓으면 그 줄의 카테고리만 바뀐다.
- [ ] 시간 카드를 줄에 놓으면 시간이 들어가고 시계에 같은 색 부채꼴이 생긴다.
- [ ] 시간 카드를 빈 곳에 놓으면 "카테고리 미지정" 줄이 생긴다.
- [ ] 시계의 부채꼴 위치가 실제 시간대와 맞다. (예: 14:00 – 17:00은 시계 아래쪽에서 약간 왼쪽)
- [ ] "계획된 시간", 헤더의 "계획", 카테고리별 합계가 서로 맞다.
- [ ] 표의 줄과 시계 부채꼴에 마우스를 올리면 서로 강조된다.

### 9-3. 수정·삭제·완료

- [ ] [수정]을 누르면 오른쪽이 "일정 수정" 모드가 되고 값이 채워진다.
- [ ] 수정 중 카테고리를 탭하면 그 일정의 카테고리가 바뀐다.
- [ ] [수정 적용] 후 표와 시계가 바뀌고 수정 모드가 끝난다.
- [ ] [삭제] 후 표와 시계에서 함께 사라진다.
- [ ] 완료 체크 시 취소선, 시계 반투명, 완료 개수, 펫 단계가 바뀐다.

### 9-4. 탭 입력과 프로필

- [ ] 카드를 탭하면 선택 표시와 하단 안내 막대가 나타나고, 표를 탭하면 반영된다.
- [ ] 같은 카드를 다시 탭하거나 [취소]·Esc를 누르면 선택이 풀린다.
- [ ] 이름과 직업을 고치면 헤더, 아바타, 탭 제목이 즉시 바뀐다. 비우면 "나의 plan", "직업 미입력"이 된다.

### 9-5. 예외 입력

- [ ] 시작이나 종료가 비어 있으면 오류 문구가 나온다.
- [ ] 시작과 종료가 같으면 오류 문구가 나온다.
- [ ] 23:00 – 01:00을 넣으면 "2시간 · 다음 날까지"로 표시되고 시계에서 0시를 넘어 이어진다.
- [ ] 겹치는 일정 두 개를 넣었을 때 "계획된 시간"이 겹친 부분을 한 번만 센다.
- [ ] [샘플 일정 채우기]·[모두 비우기]는 일정이 있을 때 확인창이 뜬다.

### 9-6. 펫

- [ ] 샘플 5개를 하나씩 체크하면 Lv.2 → 3 → 4 → 5로 오르고, 오를 때마다 반짝이 효과가 나온다. (Lv.6은 완료 7개)
- [ ] 전부 완료하면 배경이 바뀌고 펫이 계속 뛴다.
- [ ] 완료를 취소하면 레벨이 내려간다.

### 9-7. 모바일·환경

- [ ] 폭 900px 이하에서 세 영역이 세로 한 줄로 쌓이고 카테고리가 2열이 된다.
- [ ] 폭 420px 이하에서 카테고리가 1열이 된다.
- [ ] 휴대폰에서 카드를 탭한 뒤 표를 탭하면 반영된다.
- [ ] Chrome, Edge, Safari에서 같은 결과가 나오고, 인터넷 없이도 동작한다.
