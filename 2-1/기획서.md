# 하루 시간 및 스케줄 관리 투두리스트 

## 대상 사용자

- 하루 스케줄 관리가 필요한 사람들 및 미팅, 회의, 출장이 잦은 직장인 및 학생. 휴대폰에서도 내용을 확인할 수 있슴.

## 사용 목적

- 하루의 일정과 시간을 넣으면 한 페이지 내에서 스케줄 표를 생성해. 관리를 편하게 만듦.

## 화면 구성과 동작

- 화면 상단에는 사용자의 이름과 함계 "이름" plan이라는 타이틀로 헤드를 작싱
- 화면 가운데에는 스케쥴을 한눈에 볼 수 있는 시간표와 하루 24시간을 시계안에 넣어 둘이 연동 
- 왼쪽에는 미팅, 회의, 수업, 학원, 출장 등의 스케줄 카테고리가 세로로 나열.
- 출장의 경우에는 국내 출장과 해외 출장을 구분해 나열.
- 학원 및 수업의 경우 전공과 같은 본업과 주요한 파트인지 교양과 언어 학습 처럼 취미의 파트인지 구분
- 오른쪽에는 시간 작성이 가능한 시간입력 표와 시계가 그림이 존재.
- 왼쪽에서 스케줄 카테고리를 결정해서 가운데로 드래그하면 하루 스케줄 표에 추가
- 오른쪽에서 작성한 시간을 표에 드래그하면 하루 스케줄 시간에 추가
- 스케줄 표의 시간을 바탕으로 표 옆에 시계가 색으로 채워지게 구성
- 스케쥴 표에서 스케줄 삭제나 수정 버튼을 누르면 삭제 할 수 있게 진행.
- 수정은 항상 양쪽 사이드 바에서만 진행.

## 필요한 자료

- 사용자 이름
- 직업 및 직책
- 주요 스케줄 내용
- 샘플에는 가상 인물인 it 프론트엔드 개발자 김민수의 정보를 사용하고, 하단의 가상 예시 임을 표시

## 완료 기준

- HTML 파일을 열면 가운데 빈 스케줄 표가 나와 있고 양 사이드에 카테고리 내용과 시간 추가 내용이 포함되어 있어야 한다.
- 카테고리 및 시간을 선택해 드래그 했을 떄 가운데 시간표 영역의 카테고리 영역에 색이 조금 옅게 바뀌어짐.
- 시간을 바탕으로 스케줄 표 오른쪽 시간 추가 영역의 시계에 색깔이 늘어남.
-  다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다

## 추가 기능

- 스케줄 완료 여부를 체크 할 수 있음
-  전체 스케줄 완료가 하나씩 추가 될 때 마다 자신의 펫이 점점 성장하는 듯한 효과 제공

## 한계 및 비목표

(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

1. 로그인 및 개인 히스토리 기록은 하지 않습니다.
2. 시간 수정은 항상 오른쪽에 사이드바에서 실행함. 가운데 스케줄 표에서는 수정 불가.
3. 표에 작성한 시간표의 시간적 순서나 첨부 순서는 정렬하지 않음. 

## 검증 방법

(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

- 양 사이드 바에서 작성한 내용이 스케쥴 표에 잘 첨부가 되는지 체크함. 스케줄 표 내부의 변동이 생기는 지 확인함.
