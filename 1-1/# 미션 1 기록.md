## 네가 정한 영화 티어리스트 기획 내용

### 1. 사용 목적
- **개인용 웹페이지**로 만들기로 함
- 다른 사람과 공유하거나 로그인해서 쓰는 서비스가 아니라,
- **내가 본 영화를 정리하고 순위를 관리하는 용도**로 정함

---

### 2. 로그인 여부
- **로그인 기능은 필요 없음**
- 회원가입, 계정 관리, 서버 저장 없이 사용하기로 함

---

### 3. 저장 방식
- 서버나 데이터베이스 없이,
- 브라우저의 **로컬스토리지(localStorage)** 에 저장하기로 함
- 그래서 HTML 파일을 브라우저에서 열어도 영화 목록이 저장되도록 정함

---

### 4. 영화 정보 항목
영화 하나에 들어갈 정보는 다음으로 정함.

- 영화 제목
- 포스터 URL
- 장르
- 감상평
- 별점

---

### 5. 별점 방식
- 별점은 **5점 만점**으로 정함
- 별점에 따라 티어가 자동으로 나뉘도록 정함

---

### 6. 티어 분류 방식
별점에 따른 티어는 이렇게 정함.

| 별점 | 티어 |
|---|---|
| 5점 | S 티어 |
| 4점 | A 티어 |
| 3점 | B 티어 |
| 2점 | C 티어 |
| 1점 | D 티어 |

즉, 사용자가 별점을 수정하면 티어도 자동으로 바뀌게 정함.

---

### 7. 화면 스타일
- 전체 디자인은 **넷플릭스 느낌의 어두운 카드형 UI**로 정함
- 배경은 어둡게,
- 영화는 포스터 중심의 카드 형태로 보여주기로 함

---

### 8. 메인 화면 구성
- 메인 화면에는 티어별로 줄을 나눠서 보여주기로 함
- 예를 들면:

```text
S 티어  [영화] [영화] [영화]
A 티어  [영화] [영화]
B 티어  [영화]
C 티어
D 티어
```

- 각 티어 줄 안에서 영화 카드들이 **가로로 나열**되도록 정함

---

### 9. 영화 추가 방식
- 영화 추가는 페이지 안에서 **팝업 창/modal**로 하기로 함
- 새 영화 정보를 입력하면 목록에 추가됨

---

### 10. 상세보기 기능
- 영화 카드를 누르면 상세 정보를 볼 수 있게 정함
- 상세보기에서 영화 제목, 장르, 별점, 감상평 등을 확인할 수 있도록 함

---

### 11. 수정/삭제 기능
- 등록한 영화는 나중에 **수정 가능**
- 필요 없는 영화는 **삭제 가능**하게 정함

---

### 12. 드래그 정렬 기능
- 영화 카드를 드래그해서 순서를 바꿀 수 있게 정함
- 같은 티어 안에서 순서 변경 가능
- 다른 티어로도 드래그 이동 가능

---

### 13. 다른 티어로 이동했을 때
- 영화 카드를 다른 티어로 옮기면,
- 그 티어에 맞게 **별점도 자동 변경**되도록 정함

예를 들어:

- B 티어 영화 카드를 S 티어로 옮기면 별점이 5점으로 변경
- A 티어 영화 카드를 D 티어로 옮기면 별점이 1점으로 변경

---

### 14. 실행 환경
- 별도의 서버 없이,
- **HTML 파일 하나만 브라우저에서 열어서 실행**하는 방식으로 정함
- HTML, CSS, JavaScript를 모두 한 파일 안에 넣기로 함

---

### 15. 모바일 대응
- 모바일 최적화는 우선 고려하지 않기로 함
- 주로 PC 브라우저에서 보는 화면을 기준으로 제작하기로 함

---

### 16. 샘플 데이터
- 처음 열었을 때 참고할 수 있도록 **샘플 영화 데이터**를 넣기로 함
- 필요하면 샘플로 초기화할 수 있게 구성하기로 함

---

정리하면, 네가 정한 최종 기획은  
**“로그인 없이 브라우저에서 바로 실행되는 개인용 영화 티어리스트 웹페이지”**이고,  
핵심 기능은 **별점 기반 자동 티어 분류, 영화 추가/수정/삭제, 상세보기, 드래그 정렬, 로컬 저장**입니다. 잘 정리된 기획이에요.
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과): 똑같은 기획서를 넣고 HTML 파일 제공을 요구 -> 기획서의 디자인과 기능을 할 수 있는 웹페이지 구성의 HTML 파일 제공 -> 1,2 모두 기획서의 확인 기준을 다 만족시키는 기능을 제공하는 페이지를 잘 만들어 냄
- 선택한 파일명과 고른 이유: 영화 수정2 페이지 디자인이 사이즈가 딱 정당하게 보기 좋은 사이즈로 구성되어 있음.


- 고치지 않았다면 그대로 둔 이유: 기획서에 작성한 완성 기준에서 만든 내용을 모두 만족 시킴
