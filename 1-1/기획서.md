# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나

- 개인 사용자
- 로그인 없이 혼자 사용하는 영화 정리용 웹페이지

---

## 2. 무엇을 하려고

- 사용자가 본 영화를 기록하고 관리한다.
- 영화에 별점을 매겨 S/A/B/C/D 티어로 분류한다.
- 별점에 따라 티어가 자동으로 정해진다.
- 영화 카드를 드래그해서 원하는 순서로 정리한다.
- 다른 티어로도 드래그 이동할 수 있다.
- 영화별 감상평과 정보를 상세 보기에서 확인하고 수정/삭제한다.

### 티어 분류 기준

| 별점 | 티어 |
|---|---|
| 5점 | S |
| 4점 | A |
| 3점 | B |
| 2점 | C |
| 1점 | D |

---

## 3. 화면과 동작

### 메인 화면

- HTML 웹 브라우저에서 실행되는 웹페이지로 제작한다.
- 넷플릭스 느낌의 어두운 카드형 UI로 구성한다.
- 티어별로 가로 줄이 나뉘어 표시된다.
- 각 티어 줄 안에 영화 카드가 나열된다.
- 영화 카드는 포스터 이미지를 중심으로 보여준다.
- 처음 실행했을 때 샘플 영화 데이터가 표시된다.

### 영화 추가

- `카드 추가` 버튼을 누르면 영화 추가 팝업이 열린다.
- 팝업에서 영화 정보를 입력한다.
- 입력 후 저장하면 별점에 따라 자동으로 해당 티어에 추가된다.

### 영화 카드 클릭

- 영화 카드를 클릭하면 상세 보기 팝업이 열린다.
- 상세 보기에서 다음 정보를 확인한다.
  - 제목
  - 포스터 이미지
  - 장르
  - 별점
  - 감상평

### 수정 / 삭제

- 상세 보기 팝업에서 영화 정보를 수정할 수 있다.
- 상세 보기 팝업에서 영화를 삭제할 수 있다.
- 별점을 수정하면 티어도 자동으로 변경된다.

### 드래그 정렬

- 영화 카드는 드래그해서 순서를 바꿀 수 있다.
- 같은 티어 안에서 순서를 변경할 수 있다.
- 다른 티어로도 드래그 이동할 수 있다.
- 다른 티어로 이동한 경우, 이동한 티어에 맞게 별점도 변경된다.

예시:

| 이동한 티어 | 변경되는 별점 |
|---|---|
| S | 5점 |
| A | 4점 |
| B | 3점 |
| C | 2점 |
| D | 1점 |

---

## 4. 필요한 자료

### 영화 데이터

영화 카드에 저장할 정보는 다음과 같다.

- 영화 제목
- 포스터 이미지 URL
- 장르
- 별점
- 감상평
- 티어
- 정렬 순서

### 저장 방식

- 데이터는 브라우저 로컬스토리지에 저장한다.
- 서버나 로그인 기능은 사용하지 않는다.

### 샘플 데이터

- 처음 실행했을 때 샘플 영화 데이터가 포함된다.
- 샘플 데이터는 사용자가 수정하거나 삭제할 수 있다.

### 파일 구조

```text
movie-tier-list/
├── index.html
├── style.css
└── script.js
```

- `index.html`: 화면 구조
- `style.css`: 넷플릭스 느낌의 어두운 카드형 디자인
- `script.js`: 영화 추가, 상세 보기, 수정, 삭제, 드래그 정렬, 로컬스토리지 저장 기능

---

## 5. 완성 기준

다음 기능이 동작하면 완성으로 본다.

- HTML 웹 브라우저에서 실행된다.
- 처음 실행했을 때 샘플 영화 데이터가 표시된다.
- 영화 추가가 가능하다.
- 영화 정보가 브라우저 로컬스토리지에 저장된다.
- 별점에 따라 S/A/B/C/D 티어로 자동 분류된다.
- 메인 화면에서 티어별 영화 카드가 보인다.
- 영화 카드를 클릭하면 상세 보기 팝업이 열린다.
- 상세 보기에서 영화 정보를 확인할 수 있다.
- 상세 보기에서 영화 정보를 수정할 수 있다.
- 상세 보기에서 영화를 삭제할 수 있다.
- 별점을 수정하면 티어가 자동으로 변경된다.
- 영화 카드를 같은 티어 안에서 드래그 정렬할 수 있다.
- 영화 카드를 다른 티어로 드래그 이동할 수 있다.
- 다른 티어로 이동하면 해당 티어에 맞게 별점이 변경된다.
- 넷플릭스 느낌의 어두운 카드형 UI로 보인다.
